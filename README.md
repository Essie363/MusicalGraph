# Cast Light — 音乐剧演员关系图谱

把音乐剧演员之间「一起搭过戏、是同学、是搭档」的关系，画成一张可以浏览和搜索的星图。

**在线访问：https://castlight.top**

## 功能

- 搜索演员：输入姓名，快速在图谱中定位。
- 关系图谱：以星图展示演员、作品、团体之间的关系网络。
- 演员档案：生日、专业、毕业院校、籍贯、参演剧目与角色。
- 作品演员表：按角色查看一部剧的完整卡司。
- 团体视图：查看团体成员并跳转到对应演员。
- 精彩片段：关联 Bilibili / 小红书等平台的舞台片段。
- 补充与勘误：发现资料缺失或错误，可直接提交，由管理员审核后更新。

## 怎么用

1. 打开 https://castlight.top
2. 在搜索框输入演员姓名，例如「刘令飞」或「郑云龙」
3. 点击光点或名字，查看关系、档案与参演作品
4. 切换作品 / 团体 / 精彩片段，探索不同维度的图谱
5. 想帮忙完善资料，点页面里的「联系与反馈」提交补充或勘误

## 数据来源

- 演出排期与卡司：y.saoju.net
- 演员档案：公开资料与社区补充（经管理员审核）
