# MusicalGraph 音乐剧演员关系图谱

把音乐剧演员之间“一起搭过戏、是同学、是搭档”的关系，画成一张可以浏览和搜索的星图。输入演员名字，就能看到他 / 她的合作演员、CP、同学等关系，以及演过哪些剧目、扮演过哪些角色。

**线上 Demo**：[https://musicalgraph.vercel.app/](https://musicalgraph.vercel.app/)

## 核心功能

- 搜索演员：输入姓名即可在图谱中定位。
- 关系图谱：以星图展示演员、作品、团体之间的关系网络。
- 演员档案：生日、专业、毕业院校、籍贯、所属团体、参演剧目与角色。
- 作品演员表：按角色分组查看一个剧目的完整卡司。
- 团体视图：查看团体成员并跳转到对应演员。
- 精彩片段：关联 Bilibili / 小红书等平台的舞台片段。
- 补充与反馈：支持提交补充、勘误和意见反馈。

## 技术栈

| 层 | 技术 |
|---|---|
| 前端 | HTML / CSS / JS（零依赖 Canvas 图谱，桌面 + 手机可用） |
| 数据 | SQLite 单文件 + Python 数据处理脚本 |
| 后端（后续） | PocketBase（本地）、Supabase（规划中） |
| 部署 | Vercel |

## 快速体验

1. 打开上方线上 Demo 链接。
2. 在搜索框输入任意演员姓名（例如「刘令飞」或「郑云龙」）。
3. 点击光点或名字查看关系与档案。
4. 切换「作品 / 团体 / 精彩片段」观察不同维度的图谱。

## 项目结构

- `web/`：前端页面与数据快照（`index.html`、`app.js`、`style.css`、`data.js` 等）。
- `data/`：数据库快照、CSV 导出、百科抓取 JSON、精彩片段数据等。
- `docs/`：面向维护者的详细文档（部署、PocketBase、待办等）。
- `pb/`：PocketBase 本地后端配置与迁移。
- 根目录 Python 脚本：数据采集、修复、导入导出、一键刷新（`refresh_all.py`）。

## 数据来源

- 演出排期与卡司：y.saoju.net API。
- 演员档案：手动整理与百度百科。

## 参与共建

发现资料缺失或错误，可以通过站内「补充 / 勘误 / 反馈」提交；提交内容由维护者整理后入库。想从代码层面参与，可以先看 `docs/` 里的说明。

## 本地运行

```bash
# 打开网页（无需服务器）
双击 web/index.html

# 数据更新后刷新网页数据
python refresh_all.py
```

需要依赖：Python 3（部分脚本需要 requests、networkx）。
