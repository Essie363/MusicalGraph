> 有什么看不懂的，直接照着「第三步」做一遍就明白了。

## 一、先说人话：这个「后端」到底是什么？

以前网站的数据是「打包」在网页文件里的（离线快照），改数据要手动跑脚本。

现在多了一个**小服务器程序**（叫 PocketBase，就在你电脑上跑），它的作用是：

1. **存数据**——演员、剧目、关系、精彩片段的最新数据都放它那里；
2. **收提交**——网友在 Contribute 页填的内容，先进入「待审核」队列，不会直接上网站；
3. **给你审核**——你在一个管理后台里看每条提交，点「通过」它就自动进入网站，点「拒绝」就不收。

**对你（管理员）来说，每天的工作就三步：启动 → 看后台 → 审核。**

## 三、你现在要做的 5 件事（按顺序）

### 第 1 步：启动后端 + 网站（以后每次用都要做）

1. 打开项目文件夹：`E:\AI VibeCoding Project\MusicGraph`
2. **双击 `start_all.bat`**
3. 会弹出两个黑色小窗口（一个管后端、一个管网页），**不要关掉它们**
4. 浏览器会自动打开网站：**http://localhost:8080**
5. 看到页面顶部短暂提示「数据源：PocketBase 在线」= 成功

> 提示：如果双击后没弹窗口或网页打不开，见文末「常见问题」。

### 第 2 步：改管理员密码（只做一次，建议尽快）

1. 浏览器打开后台：**http://127.0.0.1:8090/_/**
2. 用 `admin@test.local` / `test1234` 登录
3. 点左下角你的头像 → 个人设置 → 改邮箱和密码 → 保存

> 这个默认密码是公开的，别人要是知道也能登录你的后台，所以最好改掉。

### 第 3 步：自己走一遍完整流程（花 10 分钟，强烈建议）

**① 在网站上提交一条测试内容**
- 打开 http://localhost:8080 → 顶部导航点 **Contribute**
- 类别选 **精彩片段** → 填 演员姓名 / 标题 / 链接 / 平台 → 来源链接填任意网址 → 点提交
- 看到「提交成功，已进入待审核」= 成功

**② 在后台审核它**
- 打开 http://127.0.0.1:8090/_/（后台）
- 左边菜单点 **submissions**（用户提交）
- 找到你刚提交的那条（状态是 pending = 待审核）
- 点开它 → 把 **status** 从 pending 改成 **approved** → 点保存

**③ 回网站看效果**
- 刷新 http://localhost:8080
- 搜索你填的那个演员 → 进详情页
- 能看到你刚加的精彩片段 = 整条流程通了 🎉

### 第 4 步：以后每天/每次的日常操作

| 想做什么 | 怎么做 |
|---|---|
| 启动网站 | 双击 `start_all.bat` |
| 审核用户提交 | 后台 http://127.0.0.1:8090/_/ → submissions → approved / rejected |
| 重新导入 SQLite 最新数据 | 项目里运行 `python import_pocketbase.py` |
| 让离线快照也更新（可选） | 运行 `python apply_pocketbase.py` 再运行 `python refresh_all.py` |
| 备份数据（重要！） | 见第 5 步 |

### 第 5 步：每周备份（防止数据丢失）

数据是这个项目最值钱的东西，请养成习惯：

- 方式一：双击 `backup_pocketbase.ps1`
- 方式二：在项目文件夹里打开 PowerShell 运行：
  `powershell -ExecutionPolicy Bypass -File backup_pocketbase.ps1`
- 备份文件存在 `data/backups/` 里，自动只保留最近 30 份

## 四、常见问题

**Q：网页打开，但没有「PocketBase 在线」提示？**
A：后端没启动。看那两个黑色小窗口是不是被关了，重新双击 `start_all.bat`。

**Q：双击 start_all.bat 后弹了窗口，但网页打不开？**
A：等 2-3 秒再刷新 http://localhost:8080；如果还不行，看窗口里有没有报错（可能是 Python 没装或没加入 PATH，重装 Python 时勾选 Add to PATH）。

**Q：后台 http://127.0.0.1:8090/_/ 打不开？**
A：后端没启动，先双击 `start_all.bat`。

**Q：忘了管理员密码？**
A：在项目文件夹运行：`pb\pocketbase.exe superuser upsert 你的邮箱 新密码`，然后就能用新密码登录。

**Q：Contribute 提交时提示「已保存为本地草稿」？**
A：后端没连上，提交先存在了浏览器里（可导出 JSON）。启动后端后重新提交即可。

**Q：端口被占用（比如 8090 已被别的程序占用）？**
A：改用别的端口启动：`pb\pocketbase.exe serve --http 127.0.0.1:8091`，网页地址后加 `?pb=http://127.0.0.1:8091` 访问。

## 五、这些文件/概念是干什么的（看一眼就够）

| 名称 | 作用 |
|---|---|
| `start_all.bat` | 一键启动（你双击它） |
| `setup_pocketbase.ps1` | 第一次安装用（已经装好了，不用再跑） |
| `backup_pocketbase.ps1` | 备份数据 |
| `import_pocketbase.py` | 把 SQLite 数据导入后端（数据同步后跑一次） |
| `apply_pocketbase.py` | 把审核通过的内容回写到本地库（可选） |
| `pb/pb_hooks/` | 审核通过后自动入库的「机器人」，不用管 |
| submissions | 后台里的「待审核队列」 |
| actors / musicals / relations / moments | 后台里的正式数据表（演员/剧目/关系/精彩片段） |
